# 18 - Ubiquitous Language & Domain Glossary

This document defines the canonical domain vocabulary of **RoomieOps AI** following the `domain-modeling` skill.

---

## Glossary of Terms

| Term | Category | Definition & Domain Invariant |
|---|---|---|
| **Household** | Core Aggregate | The top-level residential collective sharing expenses (rent, utilities, groceries). |
| **Roommate** | Core Entity | A resident of a household, with a name, contact info, UPI VPA, and room square footage. |
| **Expense** | Financial Entity | A bill or monetary liability fronted by a payer on behalf of the household. |
| **Payer** | Role | The roommate who initially paid an expense out-of-pocket. |
| **Split Rule** | Domain Policy | The mathematical rule used to divide an expense (`EQUAL`, `ROOM_AREA`, `PERCENTAGE`, `ITEMIZED`). |
| **Split Share** | Value Object | The specific financial fraction owed by an individual roommate for a given expense. |
| **Due Date** | Temporal Invariant | The calendar deadline for settling a split share before autonomous escalation begins. |
| **Escalation Stage** | State Machine | The 4-step progressive urgency status: `STAGE_1_ANNOUNCE`, `STAGE_2_NUDGE`, `STAGE_3_DEADLINE`, `STAGE_4_OVERDUE`. |
| **Payment Intent** | Value Object | A generated client-side intent payload containing a UPI Deep Link (`upi://pay`) and a QR code. |
| **Debt Graph** | Graph Structure | The complete directed graph where nodes are roommates and directed edges represent pairwise un-settled debts. |
| **Settlement** | Financial Entity | An optimized transaction generated by the Min-Cash-Flow algorithm that clears mutual debts. |
| **Habit Profile** | Behavioral Record | Historical memory stored in Firestore tracking payment velocity, on-time percentage, and habit badges. |
| **Agent Activity Log** | Audit Record | Immutable chronological log documenting every autonomous decision, tool call, and escalation trigger. |
